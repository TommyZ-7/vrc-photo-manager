検索画面 — AIタグと人数

AIタグは手動タグとは別グループ。選択したタグのいずれかに一致する写真を返します。 人数は単一の値で検索し、保存済みの推定区間 people_min〜people_max に含まれる写真を返します。

Search

左のフィルターは 290px 幅。AIタグの選択は一覧を開かず、「AIタグを選ぶ」モーダルで行います。 選択済みのタグはフィルター内にチップで残し、検索条件を一目で確認できるようにします。

02

AIタグ選択モーダル

53 件（屋外 27 / 屋内 26）を検索・絞り込みして複数選択します。 選択済みのタグはモーダル下部と検索フィルターの両方に残します。

Picker

フィルター内に 53 件を並べると縦に長くなるため、選択はモーダルに分離します。 屋外/屋内のタブは「すべて」を含む 3 状態。検索語は日本語名・英語名・タグキーのいずれでも一致させます。

AIタグを選択

検索フィルターに追加するタグを選びます。複数選択は「いずれか」で検索します。

選択中 3件 海 夜景 桜
選択したタグは「いずれか」で検索します。
操作: タブで屋外/屋内を絞り、検索語で名前・英語名・キーを絞り、チェックで複数選択。 「適用」で検索フィルターに反映し、検索を実行します。「クリア」は選択だけを空にします。 モーダルは import / manual / notification / license / uninstall と重ねません。
03

タグ別閾値モーダル

屋外/屋内のタグ別閾値と、人物の有無（presence）の閾値を 1 つのモーダルで編集します。 変更は下書きし、「保存」でまとめて反映します。

Settings → Thresholds

タグの閾値は保存後すぐに既存の photo_ai_tags.applied へ再適用されます。 presence は人数判定の有無が変わるため、次回のタグ付けから適用します。 既定値マーカー（アンバー）と現在値（ティール）を並べ、上書き状態を色と文言で示します。

04

ダッシュボード — AIタグ付けカード

右サイドのデーモンカード直下に置きます。インストール済みで、準備不足または有効なときだけ表示します。 準備完了でも未有効（not_enabled）ならカードを出しません。未導入も非表示です。 AI関連のバッジは使わず、状態はテキストと色で示します。

Dashboard

処理中は最大 3 件のジョブ進捗とキャンセルを出し、残りは件数で示します。 準備不足なら設定へ、有効なら連携・自動へ導きます。準備完了かつ未有効のときはカード自体を表示しません。 カードは新しい DB 読み取りをせず、既存の 3 秒ポーリングのスナップショットを使います。

05

通知 — トーストのみ

モデルDL完了、sidecarクラッシュ、プラグイン不整合をトーストで知らせます。 通知センターには AI セクションを追加しません。

Toasts

同じエラーコードは 1 セッション 1 回だけ。処理中ジョブの失敗が連続しても、クラッシュやリソース不足の通知で 画面を埋めません。成功トーストはダウンロード後の Ready 遷移で 1 回だけ出します。

モデルの準備が完了しました

AIタグ付けを有効にして、写真のタグ付けを開始できます。

AIタグ付けに失敗しました

推論プラグインが終了しました。ジョブは自動で再試行されます。

プラグインの状態を確認してください

モデルのハッシュが manifest と一致しません。設定画面で再確認してください。

通知ベルと通知モーダルの対象は、既存の取り込み・ライブラリ・圧縮・デーモンのまま。 AI はトーストだけで完結させます。同じ sidecar クラッシュは成功ジョブで状態がクリアされるまで再通知しません。

レビュー観点

Approval

承認をお願いしたいこと

  • 1検索フィルター: AIタグは手動タグと別グループ。複数選択は「いずれか（OR）」、人数は単一入力（0〜10）で保存区間に含まれる写真を検索。
  • 2AIタグ選択: 屋外/屋内/すべてのタブ、検索、複数選択、選択チップ、適用。53件でもフィルターを縦に伸ばさない。
  • 3タグ別閾値: presence も同じモーダル。既定値マーカー、%表示、タグ単位リセット、すべて既定に戻す、一括保存。タグは即時 / presence は次回から。
  • 4ダッシュボード: 右サイド・デーモンカード直下。インストール済みで準備不足または有効なときだけ表示。準備完了かつ未有効（not_enabled）なら非表示。準備不足 / 待機 / 実行中 / 失敗。最大3件の進捗とキャンセル。
  • 5通知: トーストのみ。モデルDL完了/失敗、sidecarクラッシュ、プラグイン不整合。同じエラーコードは1セッション1回。通知センターには追加しない。
  • 6#313: AI関連の状態バッジ・AIバッジ・variant の「使用中」バッジ・ジョブ状態バッジは無い。検索チップは選択状態の表示として残す。
