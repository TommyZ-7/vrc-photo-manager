P20

削除確認のジョブ集計失敗

ジョブ集計に失敗したとき、「依存ジョブなし」と誤認せず、未確認であることを明示して削除を止めます。

決定: 集計失敗時は削除ボタンを無効化し、「再確認」と「キャンセル」だけを出す。再確認が成功したら通常の確認状態へ戻る。危険を承知の強制削除はこの画面では出さない。
