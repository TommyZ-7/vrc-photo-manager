#404

取り込みダイアログ（フォルダ選択時）

設定は取り込みダイアログ内に置き、次回以降の既定として AppSettings に保存します。ファイルを個別に選んだ場合はセクション自体を表示しません。

推奨: ダイアログ内の2トグルで per-import に変更し、その値を既定として保存する。設定画面には別セクションを追加しない（設定の二重管理を避ける）。

フォルダ構造
フォルダ階層を維持する

サブフォルダをライブラリ内でも再現します。オフの場合は従来どおり直下へ平坦に配置します。

指定したフォルダ名も含める

選択したフォルダ自体を階層の先頭に含めます。

オン: Imported/Trip/Day1/a.jpg オフ: Imported/Day1/a.jpg
既定は両方オフ。「フォルダ階層を維持する」がオフのとき、この項目は無効になります。
既存ファイルと同名になる場合は、従来どおり連番サフィックスで保存します。上書きはしません。

既定（両方オフ）

現行と同じ平坦配置
  • Imported/
  • ├─ a.jpg
  • └─ b.jpg

階層維持オン / ルート含めない

サブフォルダだけを再現
  • Imported/
  • ├─ Day1/
  • │ └─ a.jpg
  • └─ Day2/
  •    └─ b.jpg

階層維持オン / ルート含める

選択フォルダ名も再現
  • Imported/
  • └─ Trip/
  •    ├─ Day1/
  •    │ └─ a.jpg
  •    └─ Day2/
  •       └─ b.jpg
補足

ファイル個別指定・再取り込み

ファイルを個別に選んだ場合は「フォルダ構造」セクションを出さず、従来どおり直下へ配置します。再取り込みは既存の衝突処理（連番サフィックス、上書き禁止）を維持します。

ファイル個別指定

セクション非表示
  • a.jpg → Imported/a.jpg
  • b.jpg → Imported/b.jpg

再取り込み（階層維持オン）

既存を上書きしない
  • Day1/a.jpg
  • Day1/a-1.jpg（衝突時）

圧縮派生

compressed は従来どおり除外
  • Day1/compressed/… は走査対象外
  • 階層付きでも scanner は再帰対応済み

承認チェック

  1. 取り込みダイアログ内の2トグル（階層維持 / ルート含める）でよいか。既定は両方オフ。
  2. 2つ目は1つ目がオフのとき無効化し、設定画面には別セクションを追加しない方針でよいか。
  3. 個別ファイル取り込みではセクションを出さず、再取り込みは連番サフィックスで非上書きのままでよいか。
  4. 承認後、設定保存・import コア・UI・回帰テストを1つの PR にまとめる。
