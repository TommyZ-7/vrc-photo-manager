# UI仕様

## 1. 技術

- `gpui-kit = "=0.8.0"`（`gpui-component` を含む）
- GPUI本体は `gpui-kit` が固定する `gpui-pre` 0.3.9。アプリから直接 `gpui` クレートを追加しない。
- 日本語フォントは `crates/ui/assets/NotoSansJP.ttf` をバンドルし、起動時に登録する。
- UIは `crates/ui/src/main.rs` の単一ファイル構成。状態は `App`。

## 2. 画面構成

左サイドバー + 上部バー + メイン領域。

| 画面 | 内容 |
|---|---|
| 写真 | 4列の仮想グリッド、右インスペクタ、取り込み、検索フィルタ |
| 写真詳細 | プレビュー、メタデータ、同接者、タグ追加、圧縮履歴、圧縮/ゴミ箱 |
| 圧縮設定 | プロファイル一覧、形式・品質・ロスレス・速度・リサイズ、統計、キュー |
| 検索 | 左フィルタパネル、右結果グリッド |
| ログ監視 | 稼働状態、現在のワールド、同接者、監視パス、24時間制約の注意 |
| 設定 | 写真/ログ/取り込み先、自動起動、トレイ、自動圧縮、再読込 |

### サイドバー

- 写真 / 検索 / 圧縮 / 監視 / 設定。
- 下部にライブラリ枚数と容量。
- `--demo` 時は `DEMO DATA` を表示。

### 写真一覧

- `uniform_list` による4列固定の仮想スクロール。
- 1行4枚。行高170px。
- サムネイルは `thumbnails/<id>.webp` があれば実画像、なければワールド名から決めた色のプレースホルダー。
- バッジ: 圧縮済み、未紐付け、お気に入り。
- 右インスペクタ: プレビュー、ワールド、日時、取得元、撮影者、同接者、タグ、操作。
- 一覧・検索は最大300枚。100kのページングは未実装。

### 写真詳細

- 長辺1200pxのプレビュー。8K元画像を直接UIスレッドでデコードしない。
- メタデータ: ワールド、インスタンス、取得元、撮影者、ファイル名、解像度、サイズ、パス。
- 同接プレイヤー、タグ、圧縮履歴、メモ。
- タグは入力して追加できる。削除は未実装。
- お気に入り切り替え。
- 圧縮、ゴミ箱移動（2段階確認）、一覧へ戻る。

### 圧縮設定

- 左: プロファイルカード（選択、自動/手動バッジ）。
- 右: 形式、ロスレス、速度、品質、リサイズ、アスペクト比、出力先、サフィックス。
- 統計: 圧縮数、写真数、圧縮後合計。
- キュー: 直近20件。状態、進捗、写真ID。
- 自動圧縮は元画像保持固定。手動時のみ「置換（ゴミ箱）」を選べる。

### 検索

- ワールド / プレイヤー / タグのテキスト入力。
- 日時プリセット（今日 / 7日 / 30日 / すべて）。
- お気に入りスイッチ。
- 結果は最大300件。

### ログ監視

- 稼働状態は `daemon_heartbeat` が20秒以内かで判定。
- 現在のセッション、同接者、監視パスを表示。
- ログの24時間制約を明示。

### 設定

- パス保存後、デーモン再起動で監視に反映される旨を表示。
- 自動起動・トレイ・自動圧縮のスイッチは即時DB保存。
- 自動起動はデーモンが10秒間隔で設定を拾ってOSへ反映する。

## 3. 自動更新

- `App::start_auto_refresh` が3秒間隔で以下を更新する。
  - デーモンハートビート、現在のセッション、同接者
  - 統計、圧縮キュー
  - 選択中写真のタグ・プレイヤー・圧縮履歴
- 写真枚数が変わった場合だけ一覧とサムネイルを再読込する。

| `PANEL` | `#161a20` | カード |
| `PANEL_2` | `#1b2028` | チップ・副パネル |
| `SIDEBAR` | `#12151a` | サイドバー |
| `BORDER` | `#262c36` | 枠線 |
| `TEXT` | `#e9edf5` | 本文 |

- ダークテーマ固定。
- 角丸は8〜12px。カードは `rounded_lg`、チップは `rounded_md`。
- 文字は `text_xs` / `text_sm` / `text_lg` を中心に使用。

## 5. 実装上の注意

- GPUIの `RenderImage` はBGRA前提。`load_render` でRGBA→BGRA変換を行う。
- 画像デコードは `crates/ui/src/main.rs` の `load_render` / `load_preview` に集約する。
- `gpui-kit` のバージョンを上げる場合は、`uniform_list` / `img` / `Input` / `Switch` のAPIを実機確認する。
- UIからデーモンを起動する処理は `spawn_daemon_process`。AppImageの `--background` は `run_background_supervisor`。
- `App` はDBを直接保持する。重い書き込みはデーモンに任せる。
- 3秒更新で一覧全体を再読込しないこと（サムネイル再デコードが重い）。
