# UI仕様

2026-10のUI刷新（[#27](https://github.com/TommyZ-7/vrc-photo-manager/issues/27)）後の実装を記述する。写真を主役にした構成で、ナビゲーションと状態表示は画面の端に置く。

## 1. 技術

- `gpui-kit = "=0.8.0"`（`gpui-component` を含む）。
- GPUI本体は `gpui-kit` が固定する `gpui-pre` 0.3.9。アプリから直接 `gpui` クレートを追加しない。
- 日本語フォントは `crates/ui/assets/NotoSansJP.ttf` をバンドルし、起動時に登録する。
- UIは `crates/ui/src/main.rs` の単一ファイル構成。状態は `App`。
- コンポーネントテーマは `gpui_component::init` がライト固定のため、初期化直後に `Theme::change(ThemeMode::Dark, None, cx)` でダークへ切り替える。ボタン等を個別に色指定しない。
- ネイティブタイトルバーを使う。ウィンドウの最小サイズは 1080×700、既定は 1280×820。

## 2. 画面構成

左サイドバー + ワークスペース（画面ヘッダー + 内容）。フルスクリーンビューアだけはシェル全体の上に重なる。

| 画面 | 内容 |
|---|---|
| 写真 | 幅に応じた仮想グリッド、表示切替できる右インスペクタ、取り込み、絞り込みチップ |
| フルスクリーンビューア | 全画面の画像表示、前後移動、詳細パネル。旧・写真詳細画面を統合 |
| 圧縮設定 | プロファイル一覧、形式・品質・ロスレス・速度・リサイズ、統計、キュー |
| 検索 | 左フィルタパネル、右結果グリッド |
| ログ監視 | 稼働状態、現在のワールド、同接者、監視パス、24時間制約の注意 |
| 設定 | ライブラリと起動オプション、自動圧縮、アニメーション設定 |

### 2.1 サイドバー

- 展開時 238 px、最小化時 78 px。幅は 440 ms でアニメーションする。
- ナビゲーションは5項目。写真 `GalleryVerticalEnd` / 検索 `Search` / 圧縮 `Minimize` / 監視 `Eye` / 設定 `Settings`。
- 写真にはライブラリ枚数、圧縮には実行待ち・実行中のジョブ数（0件なら非表示）を出す。検索・監視・設定は件数なし。監視は下部のステータスドットで状態を示す。
- 下部にライブラリ枚数と総容量のカード、デーモン状態（監視中 / デーモン停止）、バージョン（デモ時は `DEMO DATA`）を表示する。
- 右端にまたがる形のフローティングトグルで展開/最小化する。ツールチップに操作名と `Ctrl+B` を表示する。
- `Ctrl/Cmd+B` で切り替え。状態は `ui_sidebar_collapsed` としてDBに保存し、再起動後も維持する。
- 最小化時はラベル、件数、ストレージカード、状態テキストを隠し、アイコンを中央揃えにする。ホバーすると右側に画面名のツールチップを出す。
- 選択中の項目は `ACCENT_SOFT` の背景と2 pxのアクセントバーで示す。

### 2.2 写真

- ヘッダーは高さ72 px。「ライブラリ」24 px、その下に枚数・総容量・最終同期を出す。右側に「詳細」/「詳細を隠す」トグル（ツールチップ `Ctrl+I`）、「再読込」、「コピー取込」「移動取込」を並べる。
- 「再読込」は索引とページキャッシュを作り直し、表示中の先頭写真をアンカーとして維持する。索引・ページの読込に失敗したときはグリッドを消さず、赤いエラーバナーと再試行ボタンを出す。
- 絞り込み行はワールド / プレイヤー / 日時 / タグの4チップ（表示のみ。動作は未実装）と、右端の「並び: 新しい順」。
- グリッドは `uniform_list` による仮想スクロール。100k件でも行は全件分あり、表示範囲の写真だけを256枚ページで遅延取得する。1行の高さは196 px、画像領域は128 px、列間は16 px。
- サムネイルは表示中のカードだけを非同期デコードし、192件のLRUで保持する。同時デコードは最大4件。UIスレッドではデコードしない。
- 右端に年レールを重ねる（[2.2.1](#221-年レール)）。
- 列数は利用可能幅から算出する（カード最小幅170 px）。サイドバーとインスペクタが開いた状態で、1280×820は3列、1440×900は4列。インスペクタを隠すとそれぞれ5列 / 6列。サイドバーを最小化するとさらに1列増える。1080×700でインスペクタ表示時は2列。
- カードは角丸14 px。選択中は2 pxの `BLUE` リングと淡いグロー、ホバー時は180 msで4 px浮く。
- カードのバッジは圧縮済み / 未圧縮のドットとラベル、お気に入りのアンバードット。タイトルはワールド名、下段に日付とサイズ。
- 初回表示は600 msのフェード+14 px移動。40 ms間隔のスタッガー（最大8段、先頭24枚まで）。スクロールで行が再マウントされても再生しない。
- 右インスペクタは330 pxの列に、幅314 px・角丸18 pxのガラスカードを16 pxマージンで置く。
- インスペクタ背景は選択写真のサムネイル（256 px）の平均色。サムネイルを拡大して45%の不透明度で敷き、暗いグラデーションのスクリムを重ねる。GPUIの要素単位バックドロップブラーは使えないため、これはブラーの近似であり本物のぼかしではない。
- プレビューは16:10。写真を切り替えると、プレビューと背景色を260 msでクロスフェードする。選択直後の1回だけ再生し、インスペクタの開閉や画面復帰では再生しない。
- 内容はタイトル、日時、バッジ、メタデータ、撮影時プレイヤー、タグ、下部に「全画面表示」「圧縮」。
- ヘッダーのトグルまたは `Ctrl/Cmd+I` で表示/非表示。列幅は300 msでアニメーションし、状態は `ui_inspector_collapsed` として保存する。
- 空のときは案内カードを表示する。一覧は全件を仮想グリッドで表示し、件数上限はない。

### 2.2.1 年レール

- グリッド右端に幅88 pxのオーバーレイとして置く。リストの上に描画し、レール内のクリック・ホバーは下のカードへ通さず、ホイールスクロールだけを通す。
- 年ラベルは新しい年から順に、その年より新しい写真の累計枚数に比例した位置へ置く。写真が多い年ほど縦の領域が広くなる。
- 現在表示中の先頭写真の月を `YYYY年M月` のピルで表示する。ピルは80×18 px、角丸9 px、`PANEL_2`（94%不透明）背景に `TEXT` 色の文字で、レールのトラック上に重ね、スクロールに追従する。
- 年ラベルをクリックするとその年の先頭写真へ移動する。ラベルから8 px以内はその年へのジャンプとして扱う。
- レール上をドラッグすると、ポインタ位置に対応する写真位置へ連続的に移動する。ドラッグはレール外へポインタが出ても続く。
- ジャンプ先は `grid_row = photo_row / columns` で行へ変換し、`-(grid_row * 196 px)` を GPUI の `max_offset()`（非負のスクロール可能量）で `-max_offset..0` にクランプする。
- ラベルが16 px未満に近づく場合は、先頭の年から順に16 px以上離れたラベルだけを描く。ドットは全年に描く。
- 写真が0枚のときはレールを表示しない。

### 2.3 フルスクリーンビューア

独立した写真詳細画面は廃止し、このビューアの詳細パネルへ統合した。

- シェル全体を覆う全画面オーバーレイ。背景は暗色に選択写真の平均色を薄く重ねる。表示時は240 msでフェードインする。
- 上部バーは高さ56 px。左から「閉じる Esc」「前へ」「次へ」、ファイル名、「詳細」/「詳細を閉じる」。
- 画像は1200 pxのプレビューを `Contain` で中央に表示する。画像そのもののクリックでは閉じず、暗いレターボックスのクリックで閉じる。
- 詳細パネルは幅380 px（閉時は0）。初回は閉じた状態で開き、以降の開閉状態はセッション中だけ記憶する。幅は300 msでアニメーションし、画像領域が追従する。
- パネルはスクロール可能で、`detail_body` を共有する。内容はお気に入り、タグ追加・削除、圧縮履歴、メモの表示・編集、圧縮、ゴミ箱（2段階確認）。
- タグチップの `×` でタグを削除できる。削除は残りのタグを `set_photo_tags` で保存し、詳細とインスペクタへ即時反映する。
- メモは「編集」で複数行入力を開き、「保存」「キャンセル」で閉じる。空・空白のみは `NULL` として保存し、「メモはまだありません」に戻る。編集中の `Esc` はビューアを閉じず編集だけをキャンセルする。
- 有効な検索にタグ条件がある場合、タグ編集後に同じ条件を非同期で再検索し、先頭写真のスクロール位置を維持する。
- お気に入りとタグの編集ではビューアを閉じない。圧縮は完了メッセージを見せるため開いたまま。ゴミ箱移動に成功したときだけ閉じる。
- 起動経路は、写真カードのダブルクリック、グリッドフォーカス中の `Space` / `Enter`、インスペクタの「全画面表示」。
- 移動元は現在の写真一覧、検索から開いた場合は検索結果。端では前へ/次へが止まる（ラップしない）。移動に合わせて背後の一覧選択も更新する。
- `Left` / `Right` は上部バーにフォーカスがあるときだけ前後移動。詳細パネルの入力中は移動しない。
- 開くと「閉じる」にフォーカスする。`Tab` / `Shift+Tab` は閉じる、前へ、次へ、詳細トグル、パネル展開時はお気に入り、タグ入力、追加、メモ編集（編集中は入力欄・保存・キャンセル）、圧縮、ゴミ箱の順に循環する。フォーカスはビューア内に閉じ込め、背後のシェルは操作できない。グローバルの `Ctrl/Cmd+B` / `K` / `I` も無視する。
- 閉じると開く前にフォーカスしていた要素（通常は写真グリッド）へ戻す。

### 2.4 圧縮設定

- ヘッダーに方針（元画像を保持 / 置換（ゴミ箱））、プロファイル追加、手動圧縮。
- 左に幅280 pxのプロファイルカード一覧（選択、自動/手動バッジ、↑↓）。先頭の ↑ と末尾の ↓ は無効。並び順は保存され、再起動後も維持する。
- 右に形式、ロスレス、速度、品質、リサイズ、アスペクト比、出力先、サフィックスの編集。「複製」と「削除」を置く。
- 「複製」は「〈名前〉のコピー」を元の直後に追加する（衝突時は連番）。複製は自動適用OFFで作る。
- 「削除」は AlertDialog で確認する。`pending` / `processing` のジョブがある間は削除をブロックして理由を表示する。最後の1件も削除できない。キャンセルでは何も消えない。
- 統計は総圧縮数、写真数、圧縮後合計。キューは直近20件で、状態・進捗・写真IDを表示する。
- 自動圧縮は元画像を保持する。置換（ゴミ箱）は手動実行時のみ選べる。適用順はプロファイル一覧の並び順に従う。

### 2.5 検索

- 左に幅290 pxのガラスパネル。ワールド / プレイヤー / タグのテキスト入力、日時プリセット（今日 / 7日 / 30日 / すべて）、お気に入りスイッチ、検索 / クリア。
- 右は件数ヘッダーと仮想グリッド。カード最小幅170 pxで列数を計算し、結果は件数上限なしで全件スクロールできる。
- 検索画面にはインスペクタ列がないため、検索の利用可能幅は `search_available_width(window_width, sidebar_collapsed)` で計算し、インスペクタ分を差し引かない。1280×820で3列、1440×900で4列（サイドバー展開・フィルタパネル表示時）。
- 検索結果にも年レールを表示する。挙動は写真画面と同じ。
- カードのダブルクリックでフルスクリーンビューアを開ける。
- `Ctrl/Cmd+K` で検索画面へ移動し、ワールド入力にフォーカスする。

### 2.6 ログ監視

- 稼働状態は `daemon_heartbeat` が20秒以内かで判定する。
- 統計カード4枚（監視、現在のワールド、同接、写真）、現在のセッション、監視パスを表示する。
- VRChat本体が出力ログを24時間で削除することをアンバーの注意書きで明示する。

### 2.7 設定

- 「ライブラリ」: 写真フォルダ、ログフォルダ、取り込み先。保存後、デーモン再起動で監視に反映される旨を表示する。
- 「起動と圧縮」: 自動起動、トレイ常駐、自動圧縮、アニメーションを減らす、の各スイッチ。スイッチは即時DB保存。
- 自動起動はデーモンが10秒間隔で設定を拾ってOSへ反映する。
- 「設定を再読込」と、言語・サムネイルキャッシュ容量の表示。

## 3. キーボードショートカット

| キー | コンテキスト | 動作 |
|---|---|---|
| `Ctrl/Cmd+B` | グローバル | サイドバーの展開/最小化 |
| `Ctrl/Cmd+I` | グローバル | 写真インスペクタの表示/非表示 |
| `Ctrl/Cmd+K` | グローバル | 検索画面へ移動し、ワールド入力にフォーカス |
| `Space` / `Enter` | 写真グリッド | フルスクリーンビューアを開く |
| `Esc` | フルスクリーンビューア | 閉じる |
| `Left` / `Right` | ビューア上部バー | 前の写真 / 次の写真 |
| `Tab` / `Shift+Tab` | フルスクリーンビューア | フォーカスを循環 |

- 写真グリッドは単一のフォーカスストップ。カードをクリックするとグリッドにフォーカスする。
- 入力欄のタイプ中はグリッドのキー操作に届かない。
- ビューア表示中はグローバルのサイドバー / 検索 / インスペクタ操作を無効にする。

## 4. モーションとアクセシビリティ

- イージングは `cubic-bezier(0.22, 0.8, 0.24, 1)` 相当。依存追加なしのソルバーで実装する。
- 主な時間: サイドバー幅 440 ms、ラベル 320 ms、インスペクタ / ビューア詳細パネル 300 ms、ビューア全体 240 ms、写真切替 220 ms、カード出現 600 ms + 40 ms スタッガー、ホバー 180 ms、プレビュー / 色クロスフェード 260 ms。
- 表現は不透明度、幅、小さな位置オフセットのみ。任意要素への `scale` / `rotate` は使わない。
- 60 fps 上限（`with_max_fps(60.0)`）を指定し、アニメーション中に画像デコードやDBクエリを起こさない。
- 設定の「アニメーションを減らす」で低減できる。値は `ui_reduce_motion` として保存し、`cx.set_reduce_motion` に反映する。`with_animation` は低減時に最終状態を描画する。OS設定の自動検出はしない。

## 5. 自動更新

- `App::start_auto_refresh` が3秒間隔で以下を更新する。
  - デーモンハートビート、現在のセッション、同接者
  - 統計、圧縮キュー
  - 選択中写真のタグ・プレイヤー・圧縮履歴
- 写真枚数が変わった場合だけ索引を再構築する。3秒tickで変化を検出し、その枚数が静定するquiet-periodを待ってから1回だけ再構築する（取り込みが続く間は待機を延長する）。表示中の先頭写真をアンカーとしてスクロール位置を維持し、サムネイルはID単位で保持する。3秒ごとの再デコードは行わない。
- ヘッダーの同期表示は、デーモン稼働中は「最終同期 N秒前」、停止中は「デーモン停止」、デモ時は「デモデータ」。

## 7. デモと開発用フラグ

| フラグ | 動作 |
|---|---|
| `--demo` | 生成したサンプル画像と専用サムネイル、テンポラリDBで起動する |
| `--demo-reset` | 起動前にデモ用ディレクトリとDBを削除して作り直す |
| `--window-size WxH` | 初期ウィンドウサイズを指定（例: `1440x900`）。既定は1280×820 |
| `--background` | UIを開かず、デーモンのバックグラウンドスーパーバイザとして起動する |

- デモは18枚の1280×800 PNG（縦グラデーション、太陽、シルエット）と256 pxのPNGサムネイルを生成する。
- 保存先はOSのテンポラリ領域 `vrc-photo-manager-demo/` 配下。DBは `library.db` で、再起動しても設定が残る。写真が空のときだけシードする。
- 実ライブラリのサムネイルキャッシュには書き込まない。写真IDも実データと衝突しない。
- デモ中はサイドバー下部に `DEMO DATA` を表示する。

## 8. 実装上の注意と制約

- GPUIの `RenderImage` はBGRA前提。`load_render` でRGBA→BGRA変換を行う。画像デコードは `load_render` / `load_preview` に集約する。
- `gpui-pre` 0.3.9 には要素単位のバックドロップブラーがない。ガラス感は半透明面・枠・影・サムネイル+スクリムで近似する。ウィンドウ全体のブラー/Micaも使っていない。
- `uniform_list` は行高固定のため、日付グループ化はしない。列数だけが幅に応じて変わる。
- 一覧・検索は全件を仮想表示する。索引は全件分（100kで約2.4 MB）、ページキャッシュは最大24ページ（6,144枚）、表示サムネイルは192件LRU。
- 100kのrelease測定は索引61.5 ms / ページ0.72 ms / warm初回フレーム179–187 ms、cold-ish 226–235 ms（空DB 158–163 ms）。cold-ishはXDG/Mesaキャッシュ等を新しくした測定で、OSページキャッシュは破棄していない。真のOS cold起動は未測定。
- 年レールはX11バックエンドの実XTest入力で1280×820 / 1440×900の年クリック・レール外ドラッグ・ホイールを確認済み。レール下のカードはホバー・クリックを受けない。WaylandセッションはXTestイベントを落とすため、Waylandでの実ポインタ確認は未実施。
- ライブラリグリッドの矢印キー移動は未実装。ビューアの `Left` / `Right` は上部バーにフォーカスがあるときだけ有効。
- `gpui-kit` のバージョンを上げる場合は、`uniform_list` / `img` / `Input` / `Switch` / `Theme` のAPIを実機確認する。
- UIからデーモンを起動する処理は `spawn_daemon_process`。`--background` は `run_background_supervisor`。
- `App` はDBを直接保持する。重い書き込みはデーモンに任せる。
- 3秒更新で一覧全体を再読込しないこと（サムネイル再デコードが重い）。枚数比較でガードしている。
- 見た目の基準はLinuxの1280×820 / 1440×900。Windows実機での確認は [#9](https://github.com/TommyZ-7/vrc-photo-manager/issues/9) で追跡する。
