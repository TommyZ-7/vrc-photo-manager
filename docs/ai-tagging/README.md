# AI タグ付け（有償プラグイン）

VRC PhotoN の AI タグ付けは、写真に写る人物の有無・人数・場所とシーンタグを、
端末内のローカル推論で付ける有償プラグインです。本体アプリは無料のままで、
推論は別配布の sidecar（`d1-sidecar`）が担当します。

写真・スナップショット・推論結果を外部へ送信しません。外部通信は、利用者が
明示的に開始したモデルファイルの HTTPS ダウンロードだけです。

## できること

- 写真ごとの「キャラクターが写っているか」「人数（推定区間）」「場所
  （屋内 / 屋外 / その他）」の判定
- 場所に応じたシーンタグ（屋外27件 / 屋内26件）の付与
- AI タグを手動タグとは分離して保存・表示
- AI タグと人数による検索
- タグ別閾値と presence 閾値の調整
- ダッシュボードでの進捗確認とキャンセル
- モデル準備完了・sidecar クラッシュなどのトースト通知

## 対応環境

| 環境 | 状態 |
|---|---|
| Linux Vulkan | 実装・検証済み（M1） |
| Linux CPU | 実装・検証済み（M1 / M2）。GPU より遅い |
| Windows Vulkan / CPU | ビルド対象。M4 時点の E2E は M5 で実施予定 |
| CUDA | ビルドのみ。実機検証は M6 |
| ROCm | ビルドのみ。実機検証は M6 |

CUDA / ROCm は「未検証」として扱ってください。販売時の表記も
「Vulkan / CPU 検証済み、CUDA / ROCm はハードウェア検証待ち」です。

## 必要なもの

- 最新の VRC PhotoN 本体
- 購入したプラグイン ZIP（本体と対応する版数）
- モデルファイル（初回ダウンロード、またはオフライン取込）
  - `d1-2B-Q8_0.gguf` 約 1.85 GB
  - `mmproj-d1-2B-Q8_0.gguf` 約 203 MB
- 空きディスク約 3 GB（モデル約 2.05 GB + 作業領域）

GPU を推奨します。CPU はフォールバックとして動作しますが、1枚あたりの
処理時間が大幅に長くなります。詳しくは
[GPU 要件](gpu-requirements.md) を参照してください。

## 制限

- タグの追加・編集はできません。タグ定義は sidecar のカタログが正です。
- クラウド推論、写真の外部送信、自動更新はありません。更新はプラグイン ZIP の
  再取り込みです。
- タグ精度・presence の誤検出・人数一致は、販売前に別途手動で検証します。
  このリポジトリの自動テストは実装の正しさを確認するもので、品質評価では
  ありません。
