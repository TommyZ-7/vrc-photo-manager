# GPU 要件と性能の目安

## 対応バックエンド

| バックエンド | 状態 |
|---|---|
| Vulkan | 推奨。Linux で実装・検証済み |
| CPU | フォールバック。Linux で実装・検証済み。GPU より遅い |
| CUDA | ビルドのみ。実機検証は M6 |
| ROCm | ビルドのみ。実機検証は M6 |

Windows は Vulkan / CPU のビルド対象ですが、M4 時点の E2E は M5 で実施予定です。
Windows の実機検証が完了するまでは「Windows は未検証」として扱ってください。

## モデルとディスク

| ファイル | サイズ |
|---|---:|
| `d1-2B-Q8_0.gguf` | 約 1.85 GB（1,846,240,576 bytes） |
| `mmproj-d1-2B-Q8_0.gguf` | 約 203 MB（203,031,584 bytes） |
| 合計 | 約 2.05 GB |

モデル本体に加えて、初回ダウンロードの一時ファイル、プラグイン、ログ、
長辺 1024px の一時 JPEG 用の作業領域が必要です。空きディスクは **3 GB 以上**を
目安にしてください。

## VRAM / RAM

モデルは約 2 GB です。これに GPU バックエンドの推論作業領域が加わります。
明確な最低 VRAM / RAM は品質検証の対象で、M4 時点では確定していません。
販売前に検証環境で確定し、このドキュメントを更新します。

M1 / M2 の実測環境は次のとおりです。

- CPU: AMD Ryzen 7 5700U / 16 GiB RAM
- Vulkan: AMD Lucienne（RADV）、Vulkan 1.4

## 実測値（参考）

M1 の 4 op 合計（presence / people_count / place_class / place_tags）:

| バックエンド | 合計 |
|---|---:|
| CPU | 31.465 秒 |
| Vulkan | 6.584 秒 |

モデルロードとプロセス起動は含みません。

M2 の実 sidecar E2E（CPU、合成画像 1 枚、モデルロード込み）:

- 103.71 秒（初回）
- 121.05 秒（再確認）

これらは実装確認の参考値であり、品質・速度の保証値ではありません。CPU は
GPU より大幅に遅いため、実用上は Vulkan を推奨します。実際の写真、解像度、
GPU、ドライバによって変わります。

## 入力画像

本体が写真の表示用パス（原画、または `replace` 圧縮後の表示用派生）から
長辺 1024px・JPEG 品質 90 の一時ファイルを作り、sidecar が読みます。
元画像を sidecar に直接渡すことはありません。
