# AI タグ付けのトラブルシューティング

## プラグイン ZIP を取り込めない

- manifest の署名検証に失敗していませんか。ZIP が壊れている、配布物が違う、
  開発用 ZIP を release ビルドへ入れている、のいずれかで起こります。
- 本体とプラグインの対応版数を確認してください。manifest の
  `host_version_min` / `host_version_max` と本体バージョンが合わない場合は
  取り込めません。
- protocol version が一致しない場合も拒否されます。本体とプラグインの
  組み合わせを更新してください。

## モデルを準備できない

- **モデルなし**: 「モデルをダウンロード」または「ファイルから取り込む」で
  モデルを準備してください。
- **ハッシュ / サイズ不一致**: `model` と `mmproj` の両方が manifest と
  一致しているか確認し、再ダウンロードまたは再取込してください。
- **ライセンス同意が必要**: モデルの初回ダウンロード前に同意が必要です。
  ライセンス内容を確認してからダウンロードを開始してください。
- オフライン取込では、`model` と `mmproj` の2ファイルを選択します。片方だけ
  では取り込めません。

## Vulkan で動かない

- GPU ドライバと Vulkan ランタイムを確認してください。Linux では RADV /
  AMDVLK などの動作する Vulkan ドライバが必要です。
- 設定画面の「再確認」で probe をやり直してください。
- Vulkan が使えない場合は、バックエンドを `CPU` に切り替えてください。
  推論は動きますが遅くなります。
- CUDA / ROCm はビルドのみで、実機検証は M6 です。未検証のバックエンドを
  使う場合は Vulkan / CPU へ切り替えてください。

## メモリ不足になる

- モデルは約 2 GB です。GPU の VRAM またはシステム RAM に余裕がないと
  `out_of_memory` で失敗します。
- 他の GPU アプリを閉じるか、バックエンドを `CPU` に切り替えてください。
- ディスク不足もモデル準備の失敗原因になります。空き容量を確認してください。

## sidecar がクラッシュする / ジョブが失敗する

- 失敗したジョブは最大2回まで自動再試行されます。それ以上失敗すると
  `failed` になり、トーストで知らせます。
- 設定画面の「再確認」で probe をやり直してください。
- ログフォルダの `vrc-photon.log` / `vrc-photon-daemon.log` を確認してください。
- `plugin_not_ready` は、プラグイン・モデル・probe の準備が揃っていない状態です。
  設定画面で準備を完了してください。準備後はジョブが自動で再開します。

## CPU で遅い

CPU はフォールバックです。実測ではモデルロード込みで1枚あたり約 100〜120 秒
かかる場合があります（M2 の合成画像 1 枚）。GPU（Vulkan）を推奨します。
速度は保証値ではなく、CPU・画像・モデルによって変わります。

## タグが付かない / 付きすぎる

- タグ別閾値を確認してください。値を上げると付きにくく、下げると付きやすく
  なります。保存すると既存の AI タグへすぐ再適用されます。
- presence 閾値は次回のタグ付けから適用されます。既存の結果には影響しません。
- 「AI タグを再生成」で、現在の閾値を使って再推論できます。

## 検索結果が期待と違う

- AI タグは複数選択すると「いずれか（OR）」で検索します。すべてを含む検索では
  ありません。
- 人数は単一値です。保存済みの推定区間にその人数が含まれる写真を返します。
- 手動タグと AI タグは別条件です。手動タグのフィルターと混ざりません。

## 設定画面の AI カードが「準備完了」にならない

- プラグインが導入されているか。
- モデルが `ready` か。
- probe が保存されているか（「再確認」を実行）。
- variant が active か。

## アンインストール / 再インストール

- 既定では AI タグを残します。再インストール後も履歴として表示・検索できます。
- 「AI タグも削除する」を選ぶと、AI タグ・カタログ・閾値が削除されます。
  取り消せません。
- モデルだけを削除して、プラグインは残すこともできます。

## ログとサポート

- ログ: 設定画面の「ログ」カード、または `<data_dir>/logs/`
  - `vrc-photon.log`（UI）
  - `vrc-photon-daemon.log`（デーモン / sidecar）
- 本体共通の不具合は [トラブルシューティング](../troubleshooting.md) も
  参照してください。
