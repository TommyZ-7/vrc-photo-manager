# AI タグ付けのプライバシー

## 基本方針

AI タグ付けの推論は、端末内で動く sidecar（`d1-sidecar`）だけで行います。
写真・スナップショット・推論結果を外部のサーバーへ送信しません。

## 外部通信

外部通信は、利用者がモデル取得を明示的に開始したときの HTTPS ダウンロード
だけです。

- 接続先は署名済み manifest の `model.files[].url` に固定します。
- HTTP や `file:` は拒否します。
- ダウンロードするのはモデルファイルだけです。写真、写真パス、推論結果は
  送りません。
- オフライン取込はネットワークを使いません。
- 推論中の sidecar は DB・UI・ネットワークにアクセスしません。

## 保存するデータ

推論結果はローカルの SQLite に保存します。

- `photo_ai`: 人物の有無、presence 確率、人数の推定区間、場所、実行環境
- `photo_ai_tags`: タグごとの確率と、閾値適用後の `applied`

AI タグは手動タグ（`tags` / `photo_tags`）とは別テーブルです。手動タグを
変更しません。

## 一時ファイル

本体は推論用に長辺 1024px の一時 JPEG を
`<data_dir>/cache/tagging/` に作ります。ジョブ終了時に削除します。

## バックアップ

AI タグは写真の内容（人物の有無・人数・場所）を含みます。DB バックアップを
共有するときは個人情報として扱ってください。手動タグや写真ファイルも同様です。

## ZIP 署名

プラグイン ZIP の minisign 署名は、改ざん・破損・別配布物の取り違えを防ぐ
整合性チェックです。DRM や製品ライセンスではなく、ZIP のコピーを技術的に
防ぐものではありません。

## ライセンス同意

モデルの初回ダウンロード前に LFM Open License v1.0 への同意を求め、同意日時を
ローカルに保存します。同意なしのダウンロード要求は拒否します。

## アンインストール

- 既定では AI タグを残します。プラグイン未導入でも履歴として表示・検索できます。
- 「AI タグも削除する」を選んだ場合だけ、AI タグ・カタログ・閾値を削除します。
- 手動タグは削除しません。

## ログ

アプリのログはローカルにだけ保存します。写真パスや推論結果を必要以上に
記録しません。エラーは固定のコードと概要を記録します。
