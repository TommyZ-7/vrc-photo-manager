レビュー観点

手動タグと AIタグを、見た目でも操作でも混ぜないことを確認するための表示です。

  • ✓ AIバッジと読み取り専用。 AIセクション全体をミントのアクセントパネルで囲み、手動タグのチップとは背景・枠・色を変えています。編集できるのは手動タグだけです。
  • ✓ 確率ツールチップ。 各チップはホバー / キーボードフォーカスで「確率・モデル・生成時刻」を表示します。チップ内の % はスキャン用の補助です。
  • ✓ 人数・場所の行。 「人数（AI）: 3〜5人」「場所（AI）: 屋外」を 2 列のファクトカードで表示。0人・— も同じ位置に収まります。
  • ✓ 再生成。 フル幅の「AIタグを再生成」ボタンで、選択写真の pending ジョブを作成し WakeTagging を送ります。
  • ✓ 選択バー。 「AIタグ付け」ボタンを追加し、3 枚選択中でも個別の再生成と同じ導線を提供します。
実装メモ: AIタグは photo_ai_tags の applied = 1 を表示します。 手動タグの tags / photo_tags は変更しません。再生成は photos.ai.retag → enqueue_tagging_jobs(..., Pending) → WakeTagging。

削除警告 — AIタグ付けの件数

既存の削除確認ダイアログに「AIタグ付け」の行を追加します。待機 / 実行中 / 失敗は 既存の photos.jobs.* の表記を再利用し、AIタグ付けだけを別行で強調します。

Delete alert

未完了のジョブがあります

削除待ちに追加する前に確認してください

3 枚に未完了のジョブがあります（選択 5 枚）。

  • 圧縮 実行待ち 1
  • 送信 未実行 2
  • AIAIタグ付け 待機 128 / 実行中 2 / 失敗 1
  • 全ジョブの完了後に削除されます。
  • 送信ジョブはキャンセルされます。
  • 失敗したジョブがある場合、削除は保留され、通知されます。

警告の組み立て

既存の photos.jobs.* を再利用し、AIタグ付けの行だけを追加します。

表示キー

  • •photos.jobs.affected_selected — 「3 枚に未完了のジョブがあります（選択 5 枚）」
  • •photos.jobs.compression + photos.jobs.pending — 圧縮の件数
  • •photos.jobs.send + photos.jobs.waiting — 送信の件数
  • •photos.jobs.ai_tagging + photos.jobs.waiting / processing / failed — AIタグ付けの件数

実装メモ

deletion_warning_lines に job_status_line(tr!("photos.jobs.ai_tagging"), summary.tagging) を追加。AIタグ付けのジョブは削除をブロックし、強制削除時は cancelled にして結果を書き込みません。

待機 128 件はバックログ由来です。バックログを開始していない状態でも active なジョブとして削除を待たせます。
