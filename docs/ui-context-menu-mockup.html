タグを編集

3件の写真に共通するタグ

共通タグのみ表示しています。写真ごとのタグは単一選択で編集できます。

空文字と重複は保存時に正規化されます。AI タグはこの画面の対象外です。

状態ごとの見え方

同じメニューでも、選択と連携の状態で有効な項目が変わる。

無効項目は色を落とし、クリック不可にする

AI プラグインが未導入、モデル未準備、またはプローブ未完了。AI タグ付けだけを無効にする。

有効条件は ai_tagging_enabled && ai.ready()。メニュー側で推測しない。

キーボード

グリッドにフォーカスがあるとき、選択全体に対して同じメニューを開く。

主選択写真のカード位置
選択なしなら何もしない
入力フィールド中は開かない
検索結果も同じメニュー
Esc で閉じる
Menu/Shift+F10で起動
閉じたらキーボード起動はグリッドへ、マウス起動は元のフォーカスへ戻す。

メニュー構成

  1. 圧縮 — ホバーでサブメニュー（フォルダへ圧縮… / クリップボードへ圧縮）
  2. Discord へ送る — 単一選択のみ
  3. AI タグ付け — 複数可
  4. タグを編集… — 単一は全タグ、複数は共通タグ
  5. パスをコピー — 選択順に1行1パス
  6. フォルダを開く — 右クリックした写真の親フォルダ
  7. ゴミ箱へ移動 — 赤系で区別、既存確認ダイアログ

レビューしてほしいこと

  • 破壊的操作の赤系は強すぎないか。通常項目との差が十分か。
  • 無効項目の理由（1枚のみ / 準備中）をメニュー内に出すか、ツールチップに逃がすか。
  • 圧縮サブメニューの位置と、ホバーで開く速度。
  • タグ編集ダイアログの「共通タグのみ」の説明量。
  • 検索結果グリッドでも同じ見た目でよいか。
