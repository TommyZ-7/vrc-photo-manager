画面ごとの意図

実装時に迷わないためのメモ

01 / PHOTOS

写真一覧

10万枚を前提に、可視範囲だけを描画する仮想グリッド。日付グループと状態バッジで、探す前の全体像をつかめる。

  • 圧縮済み・未紐付け・お気に入りを色とラベルで併記
  • 選択中の写真は右インスペクタで即時確認
  • ダブルクリックまたは「詳細を開く」で詳細へ
02 / DETAIL

写真詳細

8K写真でもUIスレッドを止めないよう、長辺2048pxのプレビューを使う。文脈の取得元と信頼度を明示する。

  • ログ / XMP / 両方 / 手動をバッジで表示
  • 同接プレイヤー、タグ、メモ、圧縮履歴を1画面に集約
  • 置換は手動時のみ。実行前に確認ダイアログ
03 / COMPRESSION

圧縮設定

自動圧縮は元画像を保持して別ファイルを生成する固定運用。手動実行のときだけ「置換」を選べる。

  • 形式・品質・速度・リサイズ・出力先をプロファイル化
  • キューはDB永続化。失敗ジョブを再試行できる
  • 統計はDBから集計し、プロファイル別に表示
04 / SEARCH

検索

ワールド、プレイヤー、日時、タグ、お気に入りをカテゴリ間AND・カテゴリ内ORで組み合わせる。

  • 選択条件をチップで常時表示し、個別解除できる
  • 未紐付け件数を出し、再解析への導線を用意
  • フリーテキスト検索はMVP外。必要時にFTS5を追加
05 / MONITOR

ログ監視

常駐デーモンの状態、現在のワールド、同接者、イベント、監視パスを1画面で確認できる。

  • 24時間でログが消える制約を明示
  • 一時停止・再開、過去ログ再解析をここから実行
  • 未解析行や最終解析時刻を診断情報として表示
06 / SETTINGS

設定

パスは自動検出を優先し、失敗時だけ手動指定させる。危険操作は最後に分離する。

  • 自動起動、トレイ常駐、言語、テーマ、キャッシュ上限
  • 再スキャン、過去ログ再解析、DBバックアップ
  • アプリデータ削除は写真ファイルを消さない

画面の流れ

撮影から検索・圧縮までの基本導線

STEP 01

PNGが写真フォルダに保存される
→
STEP 02

→
STEP 03
ログと紐付け
撮影時刻からワールド・同接者を特定
→
STEP 04
一覧・検索
文脈、日時、タグで写真を探す
→
STEP 05
圧縮
自動は保持、手動は置換も選択
