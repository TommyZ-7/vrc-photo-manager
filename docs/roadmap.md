# ロードマップと残作業

## 1. 現状

- 写真索引、一覧、詳細、検索、圧縮、取り込み、ログ監視、XMP、トレイ、自動起動、Linuxパッケージまで実装済み。
- LinuxのCI/Releaseは成功。deb / AppImage / pacmanの生成を確認済み。
- Windows実機、AppImage実起動、deb/pacmanインストール後起動は未検証。
- 一覧・検索は最大300件。10万枚対応は未実装。

## 2. 優先度

### P0: リリース前に必要

| 項目 | 内容 | 受け入れ条件 |
|---|---|---|
| Windows実機検証 | トレイ、IME、自動起動、GPU、ログパス | Windows 10/11でUI起動、写真索引、ログ紐付け、圧縮が動く |
| パッケージ実起動 | deb / AppImage / pacman | 各形式でUI起動、デーモン自動起動、トレイ表示 |
| 10万枚のページング | 一覧・検索の遅延読み込み | 10万件のDBで初期表示とスクロールが実用速度 |
| ビジュアルQA | 主要画面のスクリーンショット確認 | 文字切れ、重なり、スクロール崩れがない |

### P1: 近いうちに

| 項目 | 内容 |
|---|---|
| キーボード操作 | Esc、Ctrl+F、Delete、矢印移動、Enter |
| 圧縮確認モーダル | 置換前の最終確認、プロファイル選択 |
| タグ削除・メモ編集 | 詳細画面の編集機能 |
| プロファイル管理 | 並び替え、複製、削除確認 |
| 取り込みUX | フォルダ選択、取り込み先の変更、進捗表示 |
| エラー表示 | 失敗理由の詳細、再試行ボタン |
| サムネイルLRU | キャッシュ上限の実装 |

### P2: 余力があれば

| 項目 | 内容 |
|---|---|
| IPC | UIとデーモンのコマンド/イベント通信。DB共有の置き換えまたは補完 |
| systemdユーザーサービス | deb/pacman向けの常駐管理 |
| Windows実機検証 | NSISインストーラは配布済み。自動起動、アンインストール、コード署名を確認 |
| 自動アップデート | 署名付き更新 |
| 英語UI | `rust-i18n` のカタログ追加 |
| 重複検出 | blake3による同一画像判定 |
| ワールド名解決 | 任意のVRChat API連携（認証が必要） |
| エクスポート | タグ・文脈のJSON/CSV出力 |

## 3. 明示的な非目標

- VRChatアカウントログインを必須にする。
- クラウド同期を既定で有効にする。
- 写真の完全削除を既定にする。
- 公式WebSocket（pipeline）で写真の文脈を取る（取得できない）。
- 画像編集（トリミング、色補正、合成）。
- 顔認識、AI自動タグ付け。

## 4. 未決の判断項目

以下は次回以降にユーザーへ確認する。

1. Windows配布はNSISで確定（v0.1.1）。ポータブルZIPも必要か。
2. deb/pacmanでsystemdユーザーサービスを提供するか、アプリ管理の自動起動を継続するか。
3. 10万枚対応をキーセットページングにするか、全件ID読み込み＋仮想描画にするか。
4. UIとデーモンのIPCを導入するか、SQLite共有を続けるか。
5. 英語UIをいつ入れるか。
6. 300枚上限をいつ解除するか。
7. AppImageの自動起動をデスクトップ環境ごとに検証する範囲。

## 5. リリース判定

β公開の条件:

- CIとReleaseが緑。
- Linuxの3形式が生成できる。
- 主要な写真索引・紐付け・圧縮の手動確認が通る。
- 既知の制約がREADMEとHANDOFFに書かれている。
- クラッシュやデータ消失につながる未解決バグがない。

正式版の条件:

- Windows実機検証済み。
- 10万枚の性能目標を満たす。
- バックアップ/復元手順が文書化されている。
- パッケージのインストール/アンインストールが確認済み。
