5つの変更

モックで確認できる単位に分解

01 / DESIGN

余白と階層

8pxグリッド、26pxの外周、10/12/17/24pxの文字スケール。面は「背景 → ガラス → 内容」の3層に整理し、枠線より光影で区切る。

02 / BLUR

背景ぼかし

選択写真の色をインスペクタ背景に滲ませる。ツールバーとモーダルは半透明ガラス。写真の邪魔をせず、選択の文脈を見せる。

03 / MOTION

意味のある動き

150–450ms、cubic-bezier(.22,.8,.24,1)。カードは40msずつ遅延、選択でプレビューがクロスフェード、モーダルは背景ごと沈む。

04 / ICONS

アイコンは5つだけ

ナビゲーションの写真・検索・圧縮・監視・設定のみ。操作ボタンはテキスト、状態は色と点で示す。折りたたみ時だけツールチップを足す。

05 / SIDEBAR

最小化する

238px → 78px。ラベルが消え、アイコンとツールチップだけのレールに。幅はアニメーションし、選択は保存される。

GPUI IMPLEMENTATION NOTE

gpui-pre 0.3.9 だけでなく upstream の最新 gpui 0.2.2 / main（2026-10）でも 要素単位の backdrop-filter は未対応。インスペクタは既存の 256pxサムネイルを拡大描画する近似ブラー＋半透明スクリムで実装し、全画面モーダルは 暗いスクリムで代替する。OSウィンドウの MicaBackdrop / Blurred は Windows 11 限定のため任意。サイドバーは with_animation で幅を補間し、 開閉状態は AppSettings に保存する。
