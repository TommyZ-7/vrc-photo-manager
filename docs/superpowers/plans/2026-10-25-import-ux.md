# Import UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add folder import, live progress, cancellation/resume, and collision-rename reporting to the fixed-destination import flow.

**Architecture:** Core gains an observed/cancellable import entry point plus a recursive folder collector. The UI runs every import on the background executor, streams progress through `async_channel`, and renders a compression-style modal that starts in source-picking mode and switches to progress. The result panel gains renames, remaining sources, and retry/resume actions that reuse the same runner.

**Tech Stack:** Rust stable (edition 2024), gpui-kit 0.8, `async-channel`, `rfd`, `tempfile` in tests.

**Spec:** `docs/superpowers/specs/2026-10-25-import-ux-design.md`

## Global Constraints

- Destination is always `settings.import_dir()`; there is no per-import destination UI.
- Folder import is recursive, flattens into the destination, skips `compressed/`, symlinks, and the destination subtree.
- Existing file names are never overwritten; collisions keep the `-1`, `-2` convention.
- `import_files(files, dest, mode)` keeps its current signature and behavior.
- Do not add dependencies. `async-channel`, `rfd`, `std::sync::atomic`, and `tempfile` are already available.
- All user-facing strings are Japanese and match the wording quoted in the spec.
- This is a code-only PR. `docs/features.md`, `docs/ui.md`, and issue bodies are updated in a separate docs-only PR.
- Verify with `cargo fmt --all -- --check && cargo clippy --workspace --all-targets -- -D warnings && cargo test --workspace`.

## Review Focus

- A folder that contains the import destination must not re-import files from that destination.
- Two sources with the same file name in one batch must produce distinct targets and rename rows.
- Cancelling a retry must keep the unattempted retryable failures available for another retry.
- A cancelled initial import must not register or scan the destination when nothing was imported.
- Progress must stay monotonic and end at `total` on a completed run, including skipped and failed files.

```rust
pub fn import_files_observed<F>(
    files: &[PathBuf],
    dest: &Path,
    mode: ImportMode,
    cancel: Option<&AtomicBool>,
    mut observe: F,
) -> Result<ImportResult>
where
    F: FnMut(ImportProgress),
{
    fs::create_dir_all(dest)?;
    let total = files.len();
    let mut result = ImportResult::default();
    let mut failed = 0;
    let mut partial = 0;
    observe(ImportProgress {
        processed: 0,
        total,
        imported: 0,
        skipped: 0,
        failed,
        partial,
        last_source: None,
    });
    for source in files {
        if cancel.is_some_and(|flag| flag.load(Ordering::Relaxed)) {
            result.cancelled = true;
            break;
        }
        let issues_before = result.issues.len();
        import_one(source, dest, mode, &mut result);
        result.processed += 1;
        for issue in &result.issues[issues_before..] {
            match issue.kind {
                ImportIssueKind::Failed => failed += 1,
                ImportIssueKind::PartialMove => partial += 1,
            }
        }
        observe(ImportProgress {
            processed: result.processed,
            total,
            imported: result.imported.len(),
            skipped: result.skipped,
            failed,
            partial,
            last_source: Some(source.clone()),
        });
    }
    Ok(result)
}
```

```rust
pub fn collect_folder_sources(folder: &Path, exclude: Option<&Path>) -> Result<FolderScan> {
    if !folder.is_dir() {
        return Err(CoreError::Invalid(format!(
            "not a directory: {}",
            folder.display()
        )));
    }
    let root = fs::canonicalize(folder)?;
    let exclude = exclude.and_then(|path| fs::canonicalize(path).ok());
    let mut scan = FolderScan {
        files: Vec::new(),
        issues: Vec::new(),
    };
    walk_folder(&root, exclude.as_deref(), &mut scan);
    scan.files.sort();
    Ok(scan)
}
```
