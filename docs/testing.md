# テスト方針

## 1. 自動テスト

### 実行

```bash
cargo test --workspace
```

2026-10-21時点:

- `vrc-photo-core`: 23件
- `vrc-photo-daemon`: 5件
- UI: 自動テストなし（起動確認のみ）

### coreの主なテスト

| ファイル | 内容 |
|---|---|
| `db.rs` | マイグレーション、写真UPSERT、文脈/プレイヤー、検索、キューの原子的取得 |
| `scanner.rs` | フォルダ走査、単一ファイル索引、compressed除外 |
| `photo_filename.rs` | VRChatファイル名、無効名、拡張子 |
| `log_parser.rs` | イベント解析、セッション、入退室 |
| `linker.rs` | ログ紐付け、XMPのみの紐付け |
| `metadata.rs` | XMP属性、PNG iTXtからの読み取り |
| `compressor.rs` | WebP/JPEG、リサイズ、出力名衝突回避 |
| `thumbnail.rs` | サムネイル生成、キャッシュ、存在しない元ファイル |
| `importer.rs` | コピー、移動、衝突連番、非画像スキップ |
| `settings.rs` | 設定JSONの往復、パス検出 |

### daemonの主なテスト

- ログの不完全行を次回に回す。
- 最新ログファイルの選択。
- 写真 + ログのE2E（索引 → 紐付け → 外部削除でmissing）。
- 自動圧縮E2E（プロファイル → キュー → 圧縮 → derivative）。
- notify相当の増分索引。

## 2. 追加すべきテスト

優先度順:

1. `replace` ポリシー（OSゴミ箱はモック/一時ディレクトリで検証）
2. 圧縮ジョブの複数ワーカー同時取得
3. XMPの実ファイル（VRChatが出力したPNG）での検証
4. DST/タイムゾーン境界
5. 10万件の検索クエリ性能（`photo_index_text` のignoredベンチマークで一部実施済み）
6. UIのヘッドレス操作テスト（gpui-kit test-support）
7. AppImage/deb/pacmanのインストール後起動（実機/CIコンテナ）

## 3. 手動確認チェックリスト

リリース前・大きなUI変更後に実施する。

### 写真索引

- [ ] VRChat写真フォルダを指定して起動すると一覧に出る
- [ ] 新規PNGを追加すると自動で出る
- [ ] `compressed/` 内の生成物が写真として索引されない
- [ ] 外部で削除した写真が一覧から消える
- [ ] 同名・別パスの写真が別エントリになる

### ログ・XMP

- [ ] ワールド参加後に撮った写真へワールド名が付く
- [ ] 入室中のプレイヤーが写真に付く
- [ ] 退出済みプレイヤーが付かない
- [ ] ログがない写真にXMPの撮影者/ワールドが付く
- [ ] プライベートワールドでID表示になる
- [ ] 24時間より前のログがない場合、未紐付けのままになる

### 圧縮

- [ ] 自動圧縮で元画像が残る
- [ ] 手動 `keep` で別ファイルができる
- [ ] 手動 `replace` で元画像がゴミ箱へ移る
- [ ] 出力名衝突で連番になる
- [ ] 出力先に書き込めない場合、ジョブがfailedになり元画像が残る
- [ ] キューがデーモン再起動後も再開する

### 検索・タグ

- [ ] ワールド、プレイヤー、タグ、日時、お気に入りで絞れる
- [ ] 条件クリアで全件に戻る
- [ ] タグ追加が詳細に反映される
- [ ] タグの `×` で削除でき、再起動後も消えたまま
- [ ] タグ検索中に一致タグを削除すると、その写真が結果から外れる
- [ ] メモを編集・保存でき、再起動後も残る
- [ ] メモを空にして保存すると「メモはまだありません」に戻る
- [ ] メモ編集中の `Esc` はビューアを閉じず、編集だけをキャンセルする
- [ ] メモ入力中の `Space` / `Left` / `Right` / `Tab` がビューア操作を誤発火しない

### UI・トレイ

- [ ] 3秒自動更新で監視状態が変わる
- [ ] デーモン停止時に「デーモン停止」になる
- [ ] トレイからUIを開ける
- [ ] トレイの一時停止/再開が効く
- [ ] 二重起動しない
- [ ] 削除が2段階確認になる

### パッケージ

- [ ] `.deb` をインストールしてUIが起動する
- [ ] AppImageを実行してUIが起動する
- [ ] pacmanパッケージをインストールしてUIが起動する
- [ ] パッケージ版UIからデーモンが起動する
- [ ] AppImageの自動起動が再ログイン後も動く（`$APPIMAGE --background`）
- [ ] デスクトップエントリとアイコンが表示される

## 4. 既知の未検証範囲

- Windows実機（トレイ、IME、自動起動、GPU）
- AppImageの実起動・自動起動
- deb/pacmanのインストール後起動
- 10万枚の実ライブラリ負荷（合成DBでwarm初回179–187 ms、cold-ish 226–235 ms、空DB cold-ish 158–163 ms、索引61.5 ms、ページ0.72 msを測定済み。cold-ishは予算内だが真のOS cold起動は未測定。実ライブラリでの確認は未検証）
- 実ポインタの年レール操作（X11の実XTestで年クリック・ドラッグ・ホイールを1280×820 / 1440×900で確認済み。WaylandはXTestイベントを落とすため未確認）、スクロール中の列リサイズ、スクロール中の取り込み、検索結果からのゴミ箱移動
- 実VRChatログの最新バージョン差異
- rfdのファイルダイアログ（xdg-portal環境）

## 5. CI

- PR: `test` ジョブ（fmt / clippy / test）。docs-onlyはfast-pass。
- PR（release-relevant paths）: Releaseワークフローで3形式をビルド。
- tag: 3形式をビルドしGitHub Releaseへ添付。
- `main` の必須チェックは `test`。

## 6. テスト追加のルール

- バグ修正には再現テストを追加する。
- ログ解析は匿名化した実ログフィクスチャを使う。
- 画像テストは小さな生成PNGを使い、外部ファイルに依存しない。
- サムネイルやインポートのテストは一時ディレクトリを使い、ユーザーデータディレクトリを汚さない。
