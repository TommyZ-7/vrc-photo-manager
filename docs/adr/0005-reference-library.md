# ADR-0005: 参照ライブラリ＋任意取り込み

- Status: Accepted
- Date: 2026-10-21

## Context

VRChatの写真はユーザーが既にフォルダで管理している。アプリが勝手に移動・改名すると、他のツールやユーザーの習慣を壊す。一方で、VRChat外の写真も同じライブラリで管理したい要望がある。

## Decision

- 既定は参照方式。VRChatの写真フォルダを監視し、DBに索引だけを持つ。
- 写真ファイルは移動・改名しない。
- 任意で「コピー取込」「移動取込」を提供する。操作ごとに選ぶ。
- 取り込み先は管理フォルダ（既定: ユーザーデータの `imported/`）。
- 名前衝突は連番。既存ファイルは上書きしない。
- 参照ファイルが見つからない場合は `missing` としてDBに残す。

## Consequences

- 既存の写真管理を壊さない。
- 参照のみの場合、ユーザーがファイルを移動すると `missing` になる。
- 取り込みは明示操作でのみファイルを動かす。

## Alternatives

- アプリ管理フォルダへ自動コピー: 容量が増え、既存の習慣を壊す。
- 自動移動: 危険。
