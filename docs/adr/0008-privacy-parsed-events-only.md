# ADR-0008: 生ログを保存せず解析済みイベントのみ保存する

- Status: Accepted
- Date: 2026-10-21

## Context

VRChatの出力ログには表示名、ユーザーID、環境情報などが含まれる。VRChat本体はログを24時間で削除する。写真の紐付けを後から再構築したいが、生ログを無期限に保持するとプライバシーと容量のリスクがある。

## Decision

- 生ログはアプリ側に保存しない。
- 解析済みイベント（ワールド、セッション、プレイヤーの入退室）だけをSQLiteに保存する。
- 写真の再紐付けは保存済みイベントから行う。
- パーサのバグで取りこぼした行は復元できない。
- デバッグ用の一時保存を追加する場合は、オプトイン・期間限定・警告表示を必須にする。

## Consequences

- 個人情報と容量のリスクを抑えられる。
- VRChatがログを削除した後でも、解析済みイベントから写真リンクは再構築できる。
- ログ形式の変更で過去に取りこぼしたイベントは復元できない。
- パーサ更新時は、保存済みイベントの再紐付けと新規ログの両方をテストする。

## Alternatives

- 生ログを圧縮アーカイブ: 再解析できるが、個人情報を長期保存する。
- ログを一切保存しない: 写真の紐付けができない。
