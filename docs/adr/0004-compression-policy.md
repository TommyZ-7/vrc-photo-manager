# ADR-0004: 自動圧縮は元画像保持、手動置換はゴミ箱

- Status: Superseded by [ADR-0013](0013-auto-compression-policy.md)
- Date: 2026-10-21

> この判断は ADR-0013（圧縮ポリシーを全体設定にし、自動圧縮にも適用する）で置き換えられた。履歴として残す。

## Context

自動処理で写真を不可逆に変更すると、設定ミスやエンコーダの不具合でユーザーの写真を失う。一方で、容量削減のために元画像を置換したいユーザーもいる。ユーザーは「自動は保持固定、手動時のみ都度選択」を選択した。

## Decision

- 自動圧縮は常に別ファイルを生成し、元画像を保持する。
- 手動圧縮では `keep` / `replace` を選ぶ。
- `replace` は圧縮ファイルのサイズ検証後に元画像をOSゴミ箱へ移動し、`status='missing'` にする。
- 圧縮に失敗した場合、元画像は変更しない。
- 出力ファイルは既存ファイルを上書きしない（連番）。

## Consequences

- 自動処理でデータ損失が起きない。
- 容量は元画像＋圧縮版になる。
- 置換は明示操作でのみ起きる。
- ゴミ箱移動に失敗した場合は元画像が残る（安全側）。

## Alternatives

- 自動で元画像を削除: 容量は減るが危険。
- 完全削除: 復元できないため不採用。
- 圧縮後に毎回確認: 撮影のたびに操作が必要になる。
