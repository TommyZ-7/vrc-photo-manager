# ADR-0003: 文脈取得はログ監視＋XMP補完とする

- Status: Accepted
- Date: 2026-10-21

## Context

写真に「いつ・どこで・誰と撮ったか」を記録したい。VRChatの公式WebSocket（pipeline）はフレンド状態などのAPIイベントを配信するが、ワールド・インスタンス・同接プレイヤーは配信しない。XMPは2025.3.2以降、撮影者とワールド名/IDを保存するが、他プレイヤーは含まず、プライベートワールドはID/名前も書かれないことがある。VRChatの出力ログはワールド参加とプレイヤー入退室を含むが、24時間で削除される。

## Decision

- ログ監視を主とする。
- XMPは撮影者・ワールド表示名の補完に使う。
- 公式WebSocketはMVPでは使わない。
- 生ログは保存せず、解析済みイベントのみDBに保存する。
- 写真の撮影時刻とセッション・プレイヤーの在室区間で紐付ける。

## Consequences

- ワールドと同接プレイヤーをローカルで記録できる。
- アプリ起動前の写真は、残っているログの範囲でのみ復元できる。
- プライベートワールドの表示名は取れない場合がある。
- ログ形式の変更に追従する必要がある。

## Alternatives

- XMPのみ: プレイヤーが取れない。
- 公式WebSocket: 写真の文脈に寄与しない。認証管理のコストだけ増える。
- VRChat APIでワールド名を解決: 認証と2FAが必要。将来の任意機能とする。
